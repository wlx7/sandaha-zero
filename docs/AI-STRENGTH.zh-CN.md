# AI 实力评估与增强方案（2026-11-20）

评测对象：默认模型 `models/sandaha-best.npz`（dueling_film_v2，5,107 万局自对弈，双进单出规则）。
原始数据在 [`strength-2026-11.json`](strength-2026-11.json)，可用 `scripts/strength_profile.py` 和 `scripts/strength_probes.py` 重跑。
分数单位都是"底注/局"，± 是 1 个标准误。

## 一、结论

1. 对规则 AI 是碾压，但规则 AI 叫分太激进，这个对手说明不了多少问题。
2. 自家各版本之间已经分不出高下：轻量版、不同训练量、开不开搜索，差距都在噪声里。按现在的训练方法已经到顶。
3. 叫分和投降策略找不到便宜可占：往松、往紧调都不赚。
4. 真正的差距在"读牌"：一个能看见其他三家手牌的作弊版本，每局多赢约 1.8 底注，比 AI 对规则 AI 的优势还大。现有搜索一点也没拿到这部分。
5. 没有人类对局数据，所以无法回答"相当于什么水平的人"。

## 二、实测数据

### 1. 单座位对抗（1 个 X 坐在 3 个 Y 中间，每副牌 X 轮流坐四个位置）

| X | Y（另外三家） | 局数 | X 每局得分 |
|---|---|---|---|
| sandaha-best | 规则 AI | 16,000 | **+1.33 ± 0.04** |
| 规则 AI | sandaha-best | 16,000 | **−2.76 ± 0.04**（规则 AI 46% 的局抢到庄，做庄只赢 13%） |
| sandaha-best | sandaha-lite | 16,000 | −0.00 ± 0.04 |
| sandaha-lite | sandaha-best | 16,000 | −0.10 ± 0.04 |
| sandaha-best + 搜索 | sandaha-best | 960 | +0.01 ± 0.17 |

### 2. 自对弈画像（四家都是 sandaha-best，20,000 局）

| 项目 | 数值 |
|---|---|
| 庄家胜率 | 42.4% |
| 庄家每局得分 | +2.68（三个闲家各约 −0.89） |
| 平均庄分 | 64.2；70 分占 41%，60 分占 25%，50 分占 8%，80 分占 6% |
| 看完底牌投降 | 18.3% |
| 大光 / 小光 | 14.7% / 8.8% |
| 四家都不叫 | 0.13% |
| 价值预测校准 | 定主时预测庄家得分 +2.73，实际 +2.68 |

庄家输多赢少却仍然赚，是双进单出（庄家赢了翻倍）加上投降只输 1 倍造成的：AI 把叫分当成"先看底牌再决定打不打"的便宜期权。这是规则决定的打法，探针显示它不是漏洞。

### 3. 探针：把某一项调一调，1 个改动版对 3 个原版（各 16,000 局）

| 改动 | 每局得分 |
|---|---|
| 叫分更积极（叫分估值 +0.3） | −0.09 ± 0.04 |
| 叫分更积极（+1.0） | −0.39 ± 0.05 |
| 叫分更保守（−0.3） | −0.02 ± 0.04 |
| 叫分更保守（−1.0） | −0.11 ± 0.04 |
| 永不投降 | −0.06 ± 0.04 |

### 4. 上限探针：能看见真实牌的作弊版（各 3,200 局）

候选出牌放到真实牌局里推演到底（其他人仍按原网络打），选结果最好的。

| 作弊范围 | 每局得分 | 做庄时 | 做闲时 |
|---|---|---|---|
| 只在出牌阶段 | **+1.82 ± 0.10** | +7.02（原版 +2.61） | +0.09（原版 −0.87） |
| 出牌 + 定主 | **+2.05 ± 0.10** | +7.91 | +0.09 |

这是达不到的上限，但它说明：同一个网络，只要对暗牌的判断更准，还有很大空间。
现有搜索用启发式规则猜牌，对纯网络的增益是 0（见第 1 节），差的就是猜牌的质量。

## 三、增强方案

按"预期收益 ÷ 成本"排序。训练成本按上次实测的约 2,900 局/秒（128 线程机器）估算，5,000 万局约 5 小时机器时间；下面的周期是估计，不是承诺。

### 第 0 步：先有一把尺子（约 1–2 天，几乎不花钱）

- **可被利用度**：冻结当前模型坐三家，专门训练一个模型去打它（现有训练代码的对手池机制就能做）。这个"克星"每局能赢多少，就是当前模型的真实弱点大小，也能看出它是怎么输的。
- **人类对局记录**：对战时可选保存人机对局，积累到几百局后才有外部标尺。
- 现在所有比较都是自己打自己，分不出高下不等于没有弱点。

### 第 1 步：读牌（主攻方向，预期收益最大）

- **信念网络**：用自对弈数据训练一个网络，预测每张没见过的牌在谁手里（标签是现成的）。用它替换搜索里的启发式猜牌。验收标准：搜索版对纯网络每局 ≥ +0.2（现在是 0）。
- **明牌评论家**：训练时让价值网络看到四家手牌，出牌网络只看公开信息（斗地主 AI PerfectDou 的做法）。训练信号更准，同样局数学得更好。
- 两者可以并行，信念网络改动小、见效快，建议先做。

### 第 2 步：让搜索当老师

搜索比网络强之后，把搜索选出的出牌当作训练目标蒸馏回网络。这样不开搜索的网络也变强，手机上不用多花时间。前提是第 1 步验收通过。

### 第 3 步：联赛训练

对手池加入历史版本和第 0 步的"克星"，避免自对弈在几种打法之间兜圈子。

### 不建议做的

| 做法 | 依据 |
|---|---|
| 同样配置继续加训 | 3,079 万局的检查点对最终版 50.4%，已无提升 |
| 换更大的网络 | 轻量版和主力版差距 ≤ 0.1 |
| 对局时默认开现有搜索 | 增益为 0，还更慢 |
| 手工调叫分松紧、禁投降 | 探针全部不赚 |
